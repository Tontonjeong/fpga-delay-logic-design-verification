# Contributing

This is a personal technical portfolio rather than a general-purpose open-source project. Issues that identify reproducibility problems, ambiguous specifications, or incorrect technical statements are welcome.

Before proposing a change:

1. Preserve the documented behavior of each architecture, including the different invalid-output policies.
2. Do not add fabricated timing, resource, or power values.
3. Keep ModelSim simulation, Python reference validation, and Quartus synthesis as separate evidence states.
4. Run `python scripts/validate_repository.py`.
5. Do not commit original archives, DOCX reports, tool databases, wave databases, licenses, tokens, or machine-specific absolute paths.

By contributing, you confirm that you have the right to share the proposed material. No additional license is implied.
